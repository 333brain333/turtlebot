# MCU UART2 Interface

Описание интерфейса взаимодействия с микроконтроллером по UART2 на ESP32.

## Аппаратная часть

- UART: `Serial2`
- Baudrate: `115200`
- Формат: `8N1`
- RX: пин `16`
- TX: пин `17`
- Окончание команды: `\n` (перевод строки)

> Команды отправляются текстом, разделяя параметры пробелом.

## Общая схема команды

Каждая команда начинается с ключевого слова и может содержать параметры:

```text
COMMAND_NAME param1 param2 ...
```

Пример:

```text
SET_LED 255 black
```

## Поддерживаемые команды

### `SET_PWM leftA leftB rightA rightB`

Управление ШИМ для моторов. Все значения в диапазоне `0..255`.

- `leftA` – ШИМ для `LEFT_MOTOR_A`
- `leftB` – ШИМ для `LEFT_MOTOR_B`
- `rightA` – ШИМ для `RIGHT_MOTOR_A`
- `rightB` – ШИМ для `RIGHT_MOTOR_B`

Пример:

```text
SET_PWM 0 200 0 200
```

### `SET_POSE x y theta`

Установить текущие координаты и угол робота.

- `x` – позиция по оси X
- `y` – позиция по оси Y
- `theta` – угол в радианах или градусах в зависимости от вашего применения

Пример:

```text
SET_POSE 10.5 20.0 1.57
```

### `SET_WHEELS_SPEED leftSpeed rightSpeed`

Задать целевую скорость колёс в мм/с.

- `leftSpeed` – целевая скорость левого колеса
- `rightSpeed` – целевая скорость правого колеса

Пример:

```text
SET_WHEELS_SPEED 100 100
```

### `SET_COEFF Kp Ki Kd Kff`

Обновить PID‑коэффициенты для регулировки скорости.

- `Kp` – пропорциональный
- `Ki` – интегральный
- `Kd` – дифференциальный
- `Kff` – форвард-фидбек

Пример:

```text
SET_COEFF 1.2 1.4 0.02 0.3
```

### `SET_LED brightness color`

Управление светодиодной лентой по всей длине.

- `brightness` – яркость `0..255`
- `color` – название цвета

Поддерживаемые цвета:

- `black` / `off`
- `white`
- `red`
- `green`
- `blue`
- `yellow`
- `cyan`
- `magenta`
- `orange`
- `purple`

Пример:

```text
SET_LED 255 black
SET_LED 128 red
SET_LED 200 blue
```

## Ответы от микроконтроллера

Устройство отвечает строками вида:

- `OK: ...` — команда принята и выполнена
- `ERROR: ...` — команда неправильно сформирована или неизвестна

Примеры:

```text
OK: LED updated
ERROR: Unknown command
```

## Текущая телеметрия

Каждые ~100 мс микроконтроллер отправляет статус:

```text
POS X=... Y=... Th=... ENC L=... R=... SPD L=... mm/s R=... mm/s
```

Это полезно для отладки положения, энкодеров и скорости.

## Советы

- Отправляйте команды с `\n` в конце.
- Лучше сначала проверить ответ `OK`.
- Если команда возвращает `ERROR`, проверьте пробелы и порядок параметров.

## Быстрый пример взаимодействия

```text
SET_LED 255 blue
SET_WHEELS_SPEED 120 120
SET_COEFF 1.1 1.3 0.01 0.25
```
